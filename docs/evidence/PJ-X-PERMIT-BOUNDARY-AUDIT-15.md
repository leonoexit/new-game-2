- X is included as an optional context-opening Project.
- X never gates Mine, Grove, River, collection or Person progress.

- The tested X recipe remains a comparator: 2 Wood + 1 Stone + three Work actions, with or without the selected 8G permit arm.

## 2. What the existing trace proves

Under the current A6 source-invested trace:

| Day | Shared X actions before fee choice |
| --- | --- |
| D1 | Wood ×2 + Descend ×3 + Extract CP3 Ore |
| D2 | Descend ×3 + Search Stone + Extract Stone + Work ×1 |

Both arms can complete on D3:

- X0 completes after material + Work.

The permit therefore does not create a distinct completion date in the current trace. Its only demonstrated value is an allocation/liquidity fork.

## 3. `X0 — no fee`

Contract:

```text
2 Wood + 1 Stone + three Work actions → open optional Upper-Grove context
```

Benefits:

- Project preview remains material + Work, matching the clearest M/B grammar;
- no fourth gate after Depth/source access, Stone allocation and Work;
- no permit term or service owner must be explained;
- X is already distinct through its context-opening reward, so a fee is not required to differentiate the outcome.

Tradeoff:

- Gold has less strategic infrastructure use in the minimum package;
- CP3 Ore loses the explicit sell-now versus keep-for-M decision created by permit funding;
- all three B3 Projects share the same material + Work cost shape even though their rewards differ.

## 4. `XP — selected permit layer`

Comparator contract:

```text
2 Wood + 1 Stone + three Work actions + 8G permit at final commit
→ open optional Upper-Grove context
```

Benefits:

- creates a visible Ore/Gold/material allocation fork without charging every Project;
- preserves two Gold sink shapes: recurring Seed restock and one optional strategic infrastructure payment;
- makes X's commitment grammar as distinct as its reward grammar;
- optionality keeps the extra layer from blocking a base verb or route.

Tradeoff:

- adds a fourth requirement class to a Project already linked to Mine access, Stone and Work;
- `permit` needs understandable fiction and native ownership; it cannot be an unexplained fee label;
- current trace shows allocation tension, not calendar tension—the 8G fixture does not delay D3 completion;
- risks reading as a Gold sink added for economy housekeeping rather than because Upper-Grove access genuinely requires it.
